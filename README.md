# Dev Notes

## A GDGoC Product

GDGoC@SOA (Student Chapter, CSE-ITER) is a community of passionate learners, innovators, and builders with a shared mission: empowering students through technology and collaborative learning.

Dev Notes helps students stay focused on academics by providing quick access to:

- Notes
- Hostel menu
- Code playground
- PYQs (Previous Year Questions)

The goal is to make everyday student resources simple, organized, and easy to use.
